# Experimental Windows Firewall Project

Testing Windows Firewall settings deployed with PowerShell, netsh and Group Policy,
verified by effective state, Nmap scans and firewall/Security logs, in an isolated
VMware lab (`ehub.com`, DC-01 / WIN11-01 / SRV-01 / KALI-01).

**Everything is in the [`FW Lab`](FW%20Lab/) folder:** see [`FW Lab/README.md`](FW%20Lab/README.md)
for the layout, lab details and progress.
